# Oíd Mortales — Gaucho Estudios

Juego de acción en **Unreal Engine 5** (Nanite, Lumen) con identidad **Gaucho-Core**:
ambientación histórica argentina y **combate montado** (a caballo) como diferenciador central.

> **Estado actual:** greenfield. Objetivo inmediato = **vertical slice demo (5–15 min)**
> que demuestre el *feel* del combate montado, como paso previo a **Epic MegaGrants**.

## Foco

El corazón de la demo es que el **combate montado se vea y se sienta bien**.
Todo lo demás (arte final, cinemáticas, UI) es secundario hasta que eso esté sólido.

Prioridad de desarrollo:
1. Movimiento a caballo (control, física, peso/velocidad).
2. Combate montado con **un arma** (arrancar simple: sable corvo o boleadoras).
3. Iterar *feel*/responsiveness antes de sumar armas o contenido.
4. Recién después: arte, cinemáticas, UI.
